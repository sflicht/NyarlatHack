# One learnable W/F relationship

This is a contract, not a new mechanic and not a claim that a player has learned it.

## Rule

A delivered whistle manifestation is the only reason a later fountain drink may be remapped. An admitted or applied whistle that was not delivered does not remap the fountain. Both outcomes use the existing quiet, whistle_attention, and fountain_refresh operations. State stays 0..3.

## What the player can do

Engage: whistle, see the attention warning, and later drink from a fountain.
Avoid: do not whistle.
Refuse: the host-built quiet choice spends the slot and does not arm attention.

The player-visible cue is the existing engine warning. Internal ids such as next-use-v2-W are not the cue.

## Ending

Each slot is consumed once. A missing companion, a different monster, or a missing manifestation does not inherit the effect. Save/restore does not admit again.

## Recurrence

Do not reset a consumed slot. Do not raise the use cap, cruelty budget, or effect privilege. A later program would need a new admission of an already authorized operation. That is not implemented here, and it is not a recurring haunting until an ordinary run shows the first manifestation.

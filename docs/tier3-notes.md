# Deferred Tier 3 notes — no implementation authorized

The Dreamlands may sometimes echo actual shadow-run events into the main game,
including events from rejected timelines. Gate echoes on sleep, low Sanity,
and/or Insight. They must be purely cosmetic: no game-state, time, RNG, prompt,
or cruelty-budget effect, and no hidden information. Keep echoes separate from
mandatory mutation telegraphs.

“For a moment, you remember dying here.” is proposed flavor, not an observation
of a shadow run that actually happened. Only real shadow evidence could motivate
an eventual echo. Bounded shadow checks supply evidence, not universal safety
proofs. Do not implement Tier 3 until Milestone 1's playable/replay gates pass.

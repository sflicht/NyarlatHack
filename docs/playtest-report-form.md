# Playtest report form (#44), one per session

Ask the questions **in this order**. Write the player's answers down in their
own words. Do not explain anything, or show the reveal, until questions 1–3
are written down. Keep every session, including ones where nothing was
noticed or something broke.

```text
Session: <pilot name> / <n>            Date:            Facilitator:
Build id: <revision> / <uncommitted count> / <binary sha256 prefix>
Run directory: <path>
Length: <real minutes>, last turn T:<n>, deepest Dlvl <n>, ended <died / quit / saved>
Player's roguelike experience: none / some / a lot
Knew anything about this build beforehand: no / yes (say what)

BEFORE THE REVEAL
1. Did anything strange happen? What?


2. Did you think something was reacting to you? What, and when?


3. Did it change anything you did? (For example: stopped whistling,
   avoided something.)


AFTER READING THE REVEAL
4. What did you miss?


5. Fun versus annoying, 1 (annoying) to 5 (fun):   1   2   3   4   5

6. Anything else:


FACILITATOR
What the reveal lists (admitted / delivered):
What the player reacted to during play, with T: turns:
Technical problems (crash, failed restore, other), if any:
```

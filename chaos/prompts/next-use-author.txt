Next-use author contract (trusted instructions; not a live-call authorization)
Fresh evaluation: each on_action runs in a new Lua 5.4 VM. Locals, upvalues,
globals, and closures do not persist. The host validates the returned table and
stores only state, an integer 0..3. Do not write assignment text to restore
state. Do not assume a previous call's local is still there.

Callback: return a table whose only function field is on_action. on_action
receives a copied context and returns exactly next_use_intent_v=2, op, and
state. No extra fields. Legal ops: quiet, delay, whistle_attention,
fountain_refresh. C rejects a whistle op on an F trigger and a fountain op on
a W trigger before any native effect.

Context is public and host-owned. own_witnessed is "W" only after a delivered
manifestation record, otherwise "none". Admitted or applied is not witnessed.
trigger is "W" or "F". state is the last accepted host state. There is no fate,
rng, map, or hidden target field.

Not available: standard libraries, package, require, I/O, game RNG, nh, des,
or any function that mutates the game. A candidate computes a typed proposal.
C admits and applies.

Handwritten fixture: reset counter
```lua
local n = 0
return {on_action = function(context)
  n = n + 1
  return {next_use_intent_v=2, op="quiet", state=n}
end}
```
The top-level local is an upvalue of on_action. Reloading the source in each
fresh VM resets n: successive eligible calls each propose state=1, not 1 then 2.

Handwritten fixture: explicit state
```lua
return {on_action = function(context)
  local next_state = context.state
  if next_state < 3 then next_state = next_state + 1 end
  return {next_use_intent_v=2, op="quiet", state=next_state}
end}
```
Given accepted context.state in 0..3, proposed transitions are
0->1, 1->2, 2->3, 3->3. Only the returned, validated state continues; changing
a local (or the copied context) alone does not update host state.

These teach callback memory, not recurrence or new privileges:
quiet consumes the triggering slot. Each declared family has at most one
callback, so the transition list is a boundary example, not four game uses.
Author plans and proposed state are not observed history or witness facts.

This contract is wired to offline authoring through the existing fake transport,
not a live provider. Handwritten fixtures are not model authorship.
Ordinary play and live evaluation stay gated.
